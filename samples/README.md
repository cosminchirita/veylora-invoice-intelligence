# Sample data

These files contain synthetic data only and are intended for the demonstration workflow.

- `valid-invoice.xml` — a minimal UBL invoice accepted by the demo validator;
- `valid-invoice.json` — a normalized representation for JSON import;
- `erp-ledger.csv` — ERP ledger entries used in the reconciliation explanation;
- `rejected-xxe.xml` — a negative fixture that must be rejected by the anti-XXE protection.

Do not use the negative fixture with an insecure XML parser.
