# Sample data

Aceste fișiere conțin doar date sintetice și sunt destinate fluxului demonstrativ.

- `valid-invoice.xml` — factură UBL minimală, acceptată de validatorul demo;
- `valid-invoice.json` — reprezentare normalizată pentru import JSON;
- `erp-ledger.csv` — poziții ERP folosite în explicația de reconciliere;
- `rejected-xxe.xml` — fixture negativ care trebuie respins de protecția anti-XXE.

Nu folosi fixture-ul negativ într-un parser XML nesecurizat.
