# Changelog

All notable changes are documented here. The project follows Semantic Versioning.

## [1.0.0-demo.1] - 2026-07-29

### Added

- Interactive invoice integrity dashboard with Romanian localization.
- Deterministic reconciliation, explainable risk scoring and secure file validation.
- Side-by-side duplicate invoice comparison and human approval controls.
- SHA-256 audit events, CSV formula-injection protection and evidence export.
- Architecture, domain, AI governance, privacy, security and demo documentation.
- Unit, rendered-output and demo-integrity checks with GitHub Actions and CodeQL.

### Security

- Rejects oversized files, unsupported formats and XML documents containing DTD/entity declarations.
- No production credentials, real taxpayer data or external financial connectors are included.
